# 2026-rqa-auditory-recognition

Code and manuscript for *Recurrent organization of low-structure whole-brain dynamics predicts auditory recognition performance beyond activation magnitude*.

Place the required BROAD-NESS input files at the paths in `required-inputs.txt`. Run `make analysis`, `make manuscript`, or `make all` as needed. Requires MATLAB, Typst, and Connectome Workbench available on `$PATH`.
